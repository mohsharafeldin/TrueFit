feat(auth): implement onboarding, guest mode, and advanced auth routing

This commit expands the application's core logic by introducing onboarding tracking, a dedicated guest mode, and enhanced routing capabilities for the authentication flow.

Key changes include:
- State Management: 
  - Updated `RootViewModel` to handle new `AppState` cases (`onboarding` and `guest`).
  - Added logic to evaluate whether the user should see onboarding, proceed as a guest, or login.
- Preferences Management:
  - Created `PreferencesManager` (and `PreferencesManagerProtocol`) to track `hasSeenOnboarding` using `UserDefaults`.
- Authentication:
  - Refactored `AuthManager` to conform to `AuthManagerProtocol`.
  - Added support for guest mode (`isGuest`).
  - Prepared methods for secure Keychain token storage (`login`, `logout`, `getAccessToken`).
- Routing & Dependency Injection:
  - Created `AuthRouter` to handle navigation within the authentication flows.
  - Updated `DIContainer` to initialize and inject `PreferencesManager`, `AppRouter`, and `AuthRouter`.
  - Injected routers into the SwiftUI environment in `TrueFitApp`.
