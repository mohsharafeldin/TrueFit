feat(core): implement dependency injection, routing, and app state management

This commit establishes the foundational architecture for the application, introducing structured dependency injection, app-level routing, and authentication state management. 

Key changes include:
- Dependency Injection: Created DIContainer to manage core dependencies like PersistenceController and AuthManager, replacing the unused ContainerProtocol.
- App State & Routing: 
  - Introduced RootViewModel to manage the high-level app state (splash, unauthenticated, authenticated).
  - Added RootView as the main entry point to react to state changes and switch between the auth flow and main app.
  - Implemented MainAppView with a placeholder NavigationStack and routing cases (home, cart, checkout, profile).
  - Created AppRouter for handling navigation paths.
- Authentication: Added AuthManager to handle login/logout state centrally.
- Organization: Relocated TrueFitApp.swift into the App folder for better module structure.
- Data Layer: Added initial CustomerDTO to handle remote customer data parsing.
